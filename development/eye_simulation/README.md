# Eye simulation (development scratch)

The maintained, GitHub-friendly package lives at
**[`physical_eye_simulation/`](../../physical_eye_simulation/)** at the repo
root (`python -m physical_eye_simulation.run`).

This `development/eye_simulation/` tree holds local MRI caches, annotation
`.blend` files, and experimental export scripts. Those large artifacts are
gitignored / not part of the public savepoint.
