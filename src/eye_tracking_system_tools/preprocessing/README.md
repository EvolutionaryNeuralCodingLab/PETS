# Preprocessing

Use the **Preprocessing GUI** for every step on a block folder (sync, verify, Kerr, calibration, behavior, saccades, explore). Launch and tab order are in [docs/preprocessing.md](../../../docs/preprocessing.md).

This package holds the libraries the GUI imports (`BlockSync`, `OERecording`, Kerr conversion, DLC I/O, and related helpers). There are no notebooks here.

Worked example block: `PV_106 / 2025_09_04 / block_015`.
